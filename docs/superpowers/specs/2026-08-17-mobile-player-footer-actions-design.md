# 모바일 플레이어 하단 액션 레이아웃

## 목표

멤버 목록의 활성 플레이어 하단 액션을 모바일에서 텍스트가 보이는 안정적인 두 줄 구조로 표시한다.

## 적용 범위

- 적용 조건: 화면 너비 640px 이하
- 첫째 줄: `레이드 자동 등록`, `원정대 추가`
  - 두 버튼은 동일한 너비로 부모 컨테이너를 정확히 반씩 차지한다.
- 둘째 줄: `플레이어 삭제`
  - 버튼 하나가 부모 컨테이너의 전체 너비를 차지한다.
- 모든 버튼은 아이콘과 텍스트를 함께 표시한다.
- 기존 PC 및 641px 이상 레이아웃은 유지한다.
- 641px~720px에서는 하단 버튼 텍스트가 줄바꿈되지 않도록 각 버튼의 너비와 `white-space`를 보정한다.

## 구현 방식

- 기존 `player-footer-actions`의 세 버튼은 그대로 유지한다.
- 모바일에서만 하위 액션 컨테이너를 2열 그리드로 만들고, 삭제 버튼은 전체 행을 차지하도록 배치한다.
- 모바일 전용 아이콘 버튼 크기와 텍스트 숨김 규칙을 제거한다.
- 641px~720px의 가로 배치는 유지하되, 버튼이 한 행 안에서 텍스트를 온전히 표시하도록 축소 가능한 여백을 정리한다.
- 기존 연한 빨간 outline, 버튼 동작, `aria-label`, `title`, 13px 글꼴은 유지한다.

## 검증

- 320px, 375px, 390px, 430px, 640px에서 가로 스크롤 없이 두 줄로 표시된다.
- 641px 이상에서 기존 데스크톱 버튼 배열과 텍스트가 유지된다.
- 641px, 720px에서 하단 버튼 텍스트에 불필요한 줄바꿈이 없다.
- 프로덕션 빌드가 성공한다.
